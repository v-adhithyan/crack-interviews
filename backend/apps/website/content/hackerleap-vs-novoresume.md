# HackerLeap vs. Novorésumé for a one-page tech resume

Excerpt: Compare layout options and learn how to fit relevant software experience and projects on a one-page resume.

A one-page resume can work well when you’re early in your tech career or have a tight set of relevant experience. The hard part is choosing what earns a line. This comparison is written by the HackerLeap team.

## Compare the layout constraints

Novorésumé’s Basic plan lists a one-page resume, predefined layouts, and limited font choices. Its Premium offering adds options for longer documents and more customization. Check current plan details if you want to try several layouts. [Novorésumé pricing](https://novoresume.com/pricing)

HackerLeap offers one opinionated layout with a live preview, and the public editor lets you export a PDF without signup or payment. Use the preview to see what fits with the default typography. If you want to save a private draft and return to it, you can create an account.

## Edit for the job before adjusting the page

Read the posting and pick two or three responsibilities your experience actually covers. For a backend role, an internship bullet about diagnosing slow SQL queries may deserve more space than a long list of class assignments. If you are moving into software from another field, keep the transferable accomplishment that best shows ownership, such as automating a weekly reconciliation, and describe the code or process you owned.

Open the preview after trimming repeated skills and generic responsibilities. Give the strongest project enough room to show what you built and how you verified it. Download a PDF and check the page count and readability at normal zoom. If a second page contains substantial experience the role calls for, decide whether keeping that evidence serves the application.
